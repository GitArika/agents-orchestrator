# orquestrador

Esteira de sessões de IA governadas por ClickUp: o agente pega a tarefa, trabalha
numa cópia isolada do repositório, passa pelos portões e devolve a tarefa
adiante — ou para e chama uma pessoa.

Este README ganha conteúdo completo na Tarefa 22 do plano de implementação.

## O que tem aqui

| Pasta | O que é |
| --- | --- |
| `bin/` | Os executáveis |
| `skills/` | O que um agente aciona |
| `modelos/` | Modelos de configuração |
| `docs/` | Documentação para pessoas |
| `exemplos/` | Uma esteira real, para leitura |
